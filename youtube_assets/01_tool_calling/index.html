01 · CICLO DE UNA TOOL

Del mensaje a una acción real

Cada clic activa el siguiente paso del recorrido.

01 La persona pide algo «¿Cuánto pesaba el 18 de agosto?»
→
02 El harness prepara la petición Mensajes + system prompt + tools
→
03 El LLM decide Necesita una capacidad externa
→
04 Solicita una tool Nombre + argumentos
↓
05 El harness ejecuta Valida y llama al handler
←
06 Resultado de la tool Texto o JSON serializado
←
07 El LLM continúa Ya tiene la información real
←
08 Respuesta final «Pesabas 78,4 kilos»

15 · CREATE_FEATURE_ISSUE

Una conversación puede activar un flujo externo

01 · DEFINICIÓN 02 · TOOL CALL 03 · HANDLER
toolDefinitions.ts
{
  name: "create_feature_issue",
  description:
    "Crea una issue en GitHub cuando el usuario solicita una mejora " +
    "o una nueva funcionalidad para la app.",
  inputSchema: {
    type: "object",
    properties: {
      title_summary: { type: "string" },
      conversation_excerpt: { type: "string" },
      interpretation: { type: "string" }
    },
    required: [
      "title_summary",
      "conversation_excerpt",
      "interpretation"
    ]
  }
}
LLM · tool call
{
  "name": "create_feature_issue",
  "arguments": {
    "title_summary": "Copiar comidas entre fechas",
    "conversation_excerpt":
      "Me gustaría poder copiar todas las comidas de ayer al día de hoy.",
    "interpretation":
      "El usuario quiere duplicar las comidas registradas de una fecha a otra."
  }
}
toolExecutor.ts
const createFeatureIssue = async (args, context, dependencies) => {
  await dependencies.createFeatureIssue({
    title_summary: args.title_summary,
    conversation_excerpt: args.conversation_excerpt,
    interpretation: args.interpretation
  });

  return "Issue de mejora creada en GitHub correctamente.";
};
