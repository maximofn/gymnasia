# Variantes de miniatura y título

## 1. JSON válido ≠ listo

- Texto de miniatura: `JSON VÁLIDO ≠ LISTO`
- Título del vídeo: `Tool calls en streaming: por qué un JSON válido no está listo`
- Concepto: un objeto JSON puede ser válido mientras el turno del proveedor sigue abierto.

## 2. No ejecutes aún

- Texto de miniatura: `NO EJECUTES AÚN`
- Título del vídeo: `Tool calls en streaming: evita ejecutar argumentos incompletos`
- Concepto: los fragmentos continúan llegando y la barrera de ejecución permanece cerrada.

## 3. Tres providers, una regla

- Texto de miniatura: `3 PROVIDERS 1 REGLA`
- Título del vídeo: `Tool calls en streaming: una regla para OpenAI, Anthropic y Google`
- Concepto: los tres protocolos usan eventos distintos, pero ninguno autoriza la ejecución antes del evento terminal.
