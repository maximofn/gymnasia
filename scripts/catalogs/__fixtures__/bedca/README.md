# Fixtures BEDCA inventadas

`synthetic.mjs` fabrica un catálogo mínimo y sus respuestas XML para las pruebas
de protocolo, descarga, reanudación e importación. Los IDs, nombres, descripciones,
citas, métodos y cantidades son ficticios; no se copiaron de fichas BEDCA.

Los códigos y nombres de campos del protocolo permiten comprobar el cableado
real sin distribuir los datos cuyo uso está pendiente de aclaración. Ninguna
prueba lee `alimentos/bedca/.local/` ni utiliza una API, clave o modelo real.
